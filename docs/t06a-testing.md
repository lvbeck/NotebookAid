版本：0.6.0-t06a.3。T06 已由用户验收并提交 b5dcc0f；T06-A 独立等待用户验收，尚未提交，T07 未开始。

## 行为与范围

- 新建笔记菜单增加 Delta 原生富文本；默认仍为 Markdown。旧笔记不转换。
- Delta 正文为 NotebookAidDelta / version 1 的完整 ops 快照，内部文件 content.nadelta。仅接受 insert 文档，不接受 retain/delete 增量。
- 支持当前编辑器的标题 1–3、粗体、斜体、代码、链接、引用、任务／有序／无序列表、1–8 级缩进、代码语言、基础表格及本地附件图片和尺寸。未知属性、嵌入、版本与危险地址拒绝；编辑器无法无损表达的有效文档保留源码并保护。
- 首次创建或导入 Delta：明确确认后将目标笔记本升至架构版本 5，旁边 .delta-backups 下保留升级前完整副本。仅打开旧笔记本不升级；T06.4 及更旧程序不支持架构版本 5。
- 原生交换 .nadelta 是 NotebookAidNative / version 1 JSON，包含标题、完整文档、当前附件的元数据／Base64 数据与 SHA-256。源文件不修改；导入生成新笔记 ID，附件 ID 在新笔记范围内保留。当前修订以外的历史、文件夹、标签、设置不随单篇交换文件传递，整笔记本迁移请使用已有跨笔记本导入。
- 正文最多 2 MB、最多 50000 ops；每篇笔记最多 50 个附件，单个 20 MB、合计 200 MB，原生交换完整支持同一限额。计量沿用 MiB（1024² 字节）；容器上限按 200 MiB 的 Base64 膨胀、逐文件填充和 7 MiB 文档／元数据余量计算，约 273.67 MiB。超限或附件缺失／损坏拒绝，不生成省略附件的不完整副本。哈希检测损坏，不代表来源身份可信。
- SVG 仍按 T06 清洗与离线显示；外部图片地址只显示离线占位，不自动访问。
- 导出 Markdown／HTML／TXT 有预览与损失提示，不改原笔记，不携带附件文件。完整保留附件请选择 Delta 原生交换。

## 用户测试

1. 点击新建笔记，选择 Delta；首次确认升级，检查设置中的架构版本 5 与旁边的备份目录。
2. 编辑标题／粗斜体／链接，插入任务列表、嵌套列表、表格、带语言代码块以及 PNG/SVG。调节图片尺寸并保存。
3. 源码应显示版本化 JSON；往返切换富文本、撤销重做，重开笔记和程序，确认结构、图片尺寸不变。
4. 导出选择 Delta (.nadelta)，再导入，确认新笔记及附件完整。测试 Markdown／HTML／TXT 导出预览，原文不被改变。
5. 修改 JSON 加入不支持属性／delete 操作或未知版本，确认不会覆盖已保存正文；修正后恢复正常。测试缺失附件原生导出会报错。
6. 用正文关键词搜索 Delta；检查原有三种格式、切换笔记本、自动保存和关闭时保存仍正常。
