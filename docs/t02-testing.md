# T02 测试指南

本包是技术预览，**正文仅在内存中，尚未实现笔记保存**。请只使用测试文字。T03 以后才实现正式笔记本。

当前桌面版 0.2.0-t02.4、插件 0.2.3 共用等宽 N 图标。安装新 XPI 后请检查插件管理页及工具栏按钮；若使用临时扩展，请重新载入新 XPI。旧版本保留，可退出新程序后运行旧包回退。

## 启动与退出

解压后运行 `NotebookAid.exe`，无需安装 Node.js。关闭窗口保留托盘后台；托盘菜单或“技术验证”中的“退出 NotebookAid”结束后台。双击托盘可重新打开窗口。

完整便携包为 `NotebookAid-0.2.0-t02.4-win-x64.zip`，请整体解压，不要只复制 EXE。桥接使用 Windows .NET Framework 4.x；当前机器已通过编译和运行验证。程序与 XPI 均未做发布签名，正式安装器属于 T15。

修复版使用独立目录。请先从托盘明确退出旧版，再启动新版；单实例机制会把第二次启动转给已经运行的进程。如果旧包已注册桥接，先在旧目录执行 `Register-Bridge.ps1 -Remove`，再在新版目录注册；旧版文件与数据均保留，方便回退。

## 用户验收

1. 输入中文（包括拼音候选选择），测试标题、加粗、列表、引用和代码块。切换语言与浅色／深色／系统主题。
2. 在编辑器输入“你好，我在测试”，打开“技术验证”，Markdown 源码应包含新内容；删除正文后源码同步更新。手动修改源码仍需点击“将源码载入编辑器”。执行往返检查并比较输出。当前不保证表格、任务列表、图片或任意 HTML 无损往返；展开“上次载入的原始源码”可查看转换前输入，下一次主动载入会更新该快照。
3. 点击“检查 SQLite”，确认 `integrity` 为 `ok`，含中文记录，`writes` 递增。明确退出并重启后再检查，计数应继续递增。数据库是独立诊断文件，不包含编辑器正文。
4. 主题和语言选择在重启后应保留。T02 已建立八语言资源入口；英文和简体中文为主要测试语言，其他语言部分回退英文，T14 补齐。

“文字保持一致”只比较忽略空白差异的文字，不表示格式无损。代码块语言标签、下划线等不是本阶段 Markdown 保真保证范围。标题是单独输入项，与正文分开；两者目前都只在内存中。

## Thunderbird 桥接原型

此原型仅验证启动、状态及打开窗口，不是 T10 的完整笔记 addon。提供的注册脚本会修改当前用户注册表的专用 T02 项，并在解压目录生成 `native-host.json`，不需管理员权限。请保持解压目录不变。

在解压目录打开 **Windows PowerShell**，运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Register-Bridge.ps1
```

将配套 `NotebookAid-T02.xpi` 安装到 Thunderbird 157.0.1 或使用“调试附加组件 → 临时载入”进行测试。测试包未签名；是否允许常规安装以当前 Thunderbird 提示为准。

修复版 XPI 版本为 0.2.2，`gecko.strict_min_version` 改为 `157.0`，匹配本机 Thunderbird 157.0.1 使用的 Gecko 157.0。产品验收基线仍为 Thunderbird 157.0.1，不代表已测试其他版本。

1. 完全退出 NotebookAid，在 addon 中点击“启动独立后台”。应显示进程 PID，且不弹编辑窗口。
2. 点击“打开桌面窗口”；窗口关闭后仍可查询状态。
3. 记下 PID，关闭 addon 面板后重新打开，PID 应保持不变。
4. 关闭整个 Thunderbird，确认 NotebookAid 托盘仍在且窗口可以打开；重新启动 Thunderbird 查询 PID。
5. 明确退出 NotebookAid，查询状态应失败，不应自动重启；只有再次点击“启动独立后台”才启动。

启动失败时会明确报告，不退回到可能被 Thunderbird 一起终止的普通子进程启动方式。请记录错误信息与实际版本。

## 数据与回退

- 默认测试数据：`%APPDATA%\NotebookAid-T02`，包含 SQLite 诊断数据库、UI 偏好、Electron 缓存及本地桥接运行标记；与以后正式笔记本隔离。
- `bridge-runtime.json` 含本机连接令牌，不要上传或粘贴其内容。
- 本预览不登录 AI、不发送笔记或模型请求，也不自动更新。
- 卸载测试 addon 后，在同一解压目录执行以下命令移除本包的桥接注册：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Register-Bridge.ps1 -Remove
```

- 然后明确退出应用。测试包和测试数据可由用户自行保留或删除；卸载脚本不会删除它们，也不会改动 Thunderbird 邮件或现有其他插件。

## 验证边界

自动检查与实际用户验收分开记录。模拟 Native Messaging／Windows Job 测试不能替代上述真实 Thunderbird 关闭和重启测试；当前机器测试不能证明 Windows 10 实机支持。
