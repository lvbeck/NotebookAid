## 启动与测试

明确退出旧版 NotebookAid，再运行 `release/0.4.0-t04.8/NotebookAid-win32-x64/NotebookAid.exe`。建议先新建测试笔记库；正式库测试前在退出程序后复制整个库目录作为备份。该版本仍未实现加密和定期备份。

1. 左栏默认仅显示等宽等高的“新建笔记”和“导入笔记”。点击“新建笔记”展开 Markdown、HTML、TXT 格式按钮，选择格式后才创建笔记并收起选项；再次点击新建或按 Escape 可收起。检查格式标识、标题保存及按钮与“全部笔记”之间的间距。
2. Markdown／HTML：输入中文、标题 1–3、粗体、斜体、单层列表、引用、链接和无语言代码块；切换“源码／纯文本”和“富文本”，确认内容一致。只打开、切换模式不应改写原文；富文本实际编辑会规范化源码排版。
3. 在正文使用“撤销／重做”按钮、Ctrl+Z、Ctrl+Y 或 Ctrl+Shift+Z。保存后仍能撤销；切换笔记则重置该编辑会话的撤销栈。标题输入框沿用原生文本撤销。正文历史在内存中最多 100 状态，按约 8 MiB 预算裁剪；它不是 T07 磁盘历史版本页面。
4. TXT 输入 `<b>文字</b>`、`**文字**`，确认按普通字符显示和保存，没有富文本工具栏。使用真实中文输入法测试候选、提交、撤销及定时保存。自动测试的 composition 事件不代表实机输入法测试通过。
5. 导入本地 UTF-8 `.md/.markdown/.html/.htm/.txt` 文件。标题取文件名，生成新 ID，不改变原文件，不同步后续外部文件修改。单次一文件、正文最多 2 MiB；UTF-8 BOM 去除，正文换行保留。其他编码、NUL、超限文件拒绝；可先在外部编辑器另存为 UTF-8。
6. 导入包含任务列表、嵌套列表、图片、表格或带语言代码块的 Markdown；应显示保留源码的说明，原文可编辑、保存、重开。完整 HTML 文档和带不支持属性／活动内容的 HTML 同样保留源码。不得把只读保护误当作内容丢失。
7. “导出副本…”先显示快照预览，再选择路径。测试三种导出格式：同格式保留正文源码；HTML 文件附 UTF-8 BOM 编码标记，使无 charset 声明的片段也能显示中文，正文不加包装。跨格式为本地转换，可能省略不支持格式和资源。标题用于建议文件名，不自动插入正文。导出期间原笔记的主格式、ID、正文和历史不改变。
8. 导出请选择程序和笔记库目录之外的新文件名。已有文件不覆盖，失败时保留原文件并显示错误；取消应显示取消。原始 HTML 同格式导出不清洗，可能在其他程序中执行活动内容，请先核对源码。导出成功／失败显示在导出预览下方，不把标题／正文加入消息历史。
9. 重启程序，检查三种格式、标题与正文保留；复测手动／自动保存、切库、通知成功已读、设置继承和重建索引。浅深主题下检查新增按钮、源码区和导出预览。

## 支持边界

| 内容 | T04 行为 |
|---|---|
| Markdown 标题 1–3、段落、粗体、斜体、行内代码、单层有序／无序列表、引用、HTTP(S)／mailto 链接、无语言代码块 | Quill 富文本；载入时检查转换前后的 Delta 结构，不能保持时自动转源码保护 |
| HTML 安全结构片段：p/br/h1–h3/strong/b/em/i/blockquote/pre/code/ol/ul/li/a | 安全子集富文本；仅 href 属性进入预览，转换前后结构检查不通过时保护源码 |
| Markdown 任务／嵌套列表、图片、表格、水平线、删除线、4–6 级标题、原始 HTML、引用式定义、带语言代码块等 | 原文编辑／保存／同格式导出；不声称富文本无损支持 |
| HTML 完整文档、CSS、脚本、事件属性、嵌入资源、自定义属性、复杂／嵌套结构等 | 保留原始源码，不在页面执行；富文本显示受限 |
| TXT | 纯文本编辑；同格式导出保留原文 |
| 跨格式转换 | 显式预览的独立副本；纯文本会失去格式，受限 HTML 清洗会省略脚本、样式及资源；不承诺任意格式无损 |
| 图片、附件与表格编辑 | T04 不载入外部资源，不提供附件管理；图片附件在 T06，表格富文本暂不支持 |

清洗与 CSP、主进程网络拦截共同限制笔记预览；链接点击不自动打开外部地址。导入文件原文只保存在笔记库，预览不会执行脚本或加载 img/iframe/style。笔记不发送到大模型或其他网络服务。

## T04.5 源码保护诊断

- Markdown 提示明确标识 Markdown，逐项列出任务列表、嵌套列表、图片、表格、分隔线、代码语言等限制及调整建议；提供首个可定位行号和出现次数。
- HTML 提示逐项显示不支持的标签和属性，例如 `<div>`、`<div> class`、`<img>`。位置为解析后 DOM 元素序号，不冒充源码行号。
- 无须删除这些内容即可保存源码。安全清理与富文本支持范围是两个不同规则；不会为了适配编辑器自动删除安全的内容。
- 修改源码后点击“富文本”重新检查；检查完成前明确显示旧诊断待更新。仍不支持则保留源码编辑。
- 使用 test_markdown.md 验证六类限制，代码块中的列表/引用定义文本不应误报。HTML 导入后检查属性名称、源码保存及重开。

## T04.7 图片、基础表格和代码语言

- 图片：本地 PNG/JPEG 通过图片按钮或拖入嵌入正文；数据仍受正文 2 MiB 限制。远程/相对地址保留为引用，但只显示离线占位图，不自动访问网络或本地文件。支持 alt/title 和 HTML 图片尺寸；本步不包含独立附件存储、远程下载或图片裁剪。
- HTML 新导入图片保留安全 src 引用；脚本、事件、危险协议及活动资源仍清理。隔离预览不加载外部图片。此前版本已移除的 src 无法凭空恢复，需要重新导入原文件。
- 表格：普通矩形表格保留首行表头、文字格式和列对齐，可插入 3×3 表格及增删行列。Markdown 使用第一行作为表头，HTML 保留 th/td。合并单元格、嵌套表格、复杂单元格结构继续保护源码。
- 代码：支持 plain、python、javascript、typescript、json、bash、css、xml、sql、java、cpp、csharp、markdown。光标放入代码块后通过代码语言控件设置；语言标签保存并使用本地 highlight.js 高亮。未知语言/额外 fence 参数仍保护源码。
- 验收：图片插入后修改正文并保存重开；表格编辑单元格、增删行列并核对 Markdown/HTML；分别修改 Python/JavaScript 代码并切换模式保存，测试撤销重做。
- 综合 test_markdown.md 仍含分隔线，故整篇仍需源码保护；本步明确不实现分隔线。测试富文本请使用去掉分隔线的副本，不改变原附件。
