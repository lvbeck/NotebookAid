## 操作

1. 在指定笔记本设置中点击“恢复备份”。第一次窗口标题是“选择备份来源（.nabackup 文件夹）”；选择包含 `backup.json` 和 `notebook` 的具体快照，不是存放多个快照的上级目录。
2. 第二次窗口标题是“选择恢复目标（原笔记本目录或新的空目录）”，默认定位该笔记本目录。
3. 选择该笔记本原目录可原地恢复；选择新的空目录仍使用恢复到新位置的方式。其他非空目录、其他已登记笔记本、备份来源及其父子目录、程序目录和链接路径会被拒绝，并显示具体原因。
4. 统一 CDK 确认窗口列出来源、目标及本次操作的说明。取消不创建临时恢复目录，也不替换原数据；编辑区在开始操作前按现有流程保存未保存内容。

## 原地恢复顺序

先校验备份清单、文件 SHA-256 和笔记本 ID，再在原目录的同级目录 `原目录.restore-staging-UUID` 中复制和校验。临时副本完成笔记、历史、附件及加密结构检查后才开始替换。

释放原笔记本写锁前创建恢复保护记录和独立事务锁，阻止其他程序在替换间隙打开笔记本。原目录更名为 `原目录.restore-rollback-UUID`，临时副本移至原路径，再次打开并校验。成功后清除恢复保护记录，路径不变，保留回滚副本并在设置页显示其路径。不会自动删除回滚副本。

替换阶段失败时尝试自动恢复原目录。已经放入原路径的恢复副本会移回临时目录，恢复前的原目录重新放回原路径。完成后显示“已自动回滚”；只列出实际保留的副本位置。

恢复保护记录原子写入原目录旁 `.notebookaid-restore-哈希.json`，相邻 `.sqlite` 提供进程间事务锁。重新打开笔记本时检查未完成记录：已校验完成的恢复保留结果；其他有完整记录的中断阶段尝试回滚原目录。恢复记录必须与已登记路径、笔记本 ID 和固定生成的同级目录相符，拒绝可疑路径。

## 加密与失败边界

加密材料按原始密文复制，不保存主密码、不产生解密的临时笔记。锁定的备份可做字节及结构校验，认证正文仍需解锁验证。恢复后需要使用备份时的主密码或恢复密钥；恢复前的回滚副本保留当时的加密材料。

恢复还原备份时的安全设置。如果所选备份早于加密开启，其笔记可能仍是明文；当前密码也不会替换备份中的密码。Passkey 应用门禁不属于笔记本备份，不随本次恢复更改。

自动回滚也可能因权限、文件占用或磁盘故障失败。此时不删除保留数据，显示明确提示和保留路径，重新打开笔记本会再次尝试恢复；不要删除这些目录或改用忽略恢复保护记录的旧程序。硬件断电、磁盘损坏和杀毒软件长期占用不是已验证保证。校验失败或磁盘写入失败可能留下临时目录，程序不自动删除它。

成功后的回滚副本是完整笔记本目录，不是 `.nabackup` 快照。如需手动撤回成功恢复，应先退出应用，保留恢复后的原目录副本，再将回滚目录更名回原路径。不要合并覆盖文件，不要删除唯一副本。
