## 入口与行为

- 编辑模式切换同一操作区提供“附件 · 数量”，展开浮层后添加、查看、导出、重命名。面板支持 Esc、外部点击和关闭按钮。
- Quill 图片按钮选择本地文件，存入笔记本后插入图片引用；已有图片可在附件面板再次插入。PNG/JPEG/GIF/WebP 按文件内容识别。普通文件也可添加；不会自动执行文件或加载外部资源。
- 单个文件上限 20 MB；每篇笔记最多 50 个、合计 200 MB。同名按忽略大小写及 Unicode NFKC 比较，添加时自动编号；重命名为已存在名称会拒绝。
- 图片可在应用内查看；不超过 1 MB 的 UTF-8 文本以转义纯文本显示。其他文件提供明确提示，可导出副本后自行选择应用查看。
- 导出附件不覆盖已有文件，不允许写入程序、已登记笔记本或应用配置目录。源文件由原生文件选择器选择，页面不能提交任意磁盘读取路径。
- 正文使用 `attachments/<attachment-id>` 引用图片，磁盘文件使用稳定 ID；名称、文件夹、笔记标题变化均不改变路径。旧笔记已有 Base64 图片不自动转换，旧的外部图片继续离线保留。
- 删除正文中的图片不自动删除附件；附件和历史所引用文件保留。永久清理与回收站生命周期在 T07 实现。普通 Markdown/HTML/TXT 导出仍是正文副本，不是包含附件的完整归档；需要完整转移请使用“从其他笔记本导入”，单个附件可独立导出。

## 格式升级与回退

首次添加附件时提示升级到笔记本 schemaVersion 4，并在原笔记本旁的 `<目录名>.attachment-backups/<随机ID>` 创建经过哈希核对的完整副本；备份失败不升级。旧程序不能打开格式 4。新程序继续打开格式 1/2/3，无附件笔记本不因打开而升级。

新元数据在修订中保存附件清单（ID、名称、字节数、SHA-256、媒体类型）；文件存于 `notes/<note-id>/attachments/<attachment-id>`。先写入并落盘文件，再发布修订 head；写入失败保留原修订，未发布文件不自动清除。缺失或损坏不隐藏正文，附件面板标记不可用，禁止预览和导出错误字节。

跨笔记本导入同时验证和携带所有可达历史中的附件，遇到缺失／损坏即停止；源目录保持不变。目标升级为兼容来源所需的格式，保留既有导入备份与回滚机制，单次导入仍限制 256 MB 原生数据。

程序回退可退出后解压保留的 0.5.0-t05a.11 ZIP。已经升级的笔记本请保留当前目录，再把上述笔记本备份恢复至另一个目录并在旧版打开；不要用旧程序直接改格式 4 数据。测试程序目录部署继续不创建备份。

## 建议验收

1. 在测试笔记本添加文本、图片和其他文件，观察首次升级提示；取消后无新附件。
2. 重复添加同名文件，重命名、尝试重名及非法名称；关闭重开，确认附件内容和名称。
3. 图片按钮插入后保存，切源码、切回富文本，再重启；图片仍显示且源码引用不变。
4. 将笔记移入不同文件夹、重命名文件夹后检查；从此笔记本导入另一个笔记本，确认附件随同历史转移。
5. 仅在测试副本中移动或破坏一个附件文件，确认正文可打开，附件显示缺失／损坏。
6. 查看文本中 HTML/script 内容应按纯文本显示；导出附件并比较原文件；重复导出到同一路径应拒绝覆盖。
7. 浅深主题、窄窗口、八语言、键盘关闭面板；附件成功消息默认已读，失败保留在通知中心。

Windows 10、真实大容量笔记本、第三方查看程序及长时间运行仍需用户实机验证；T06 未实现 PDF/Office 专用预览或自动清理历史附件。

## 0.6.0-t06.3 SVG 与图片尺寸

此前 .1/.2 的 SVG 不支持限制已解除。Quill 图片按钮可选本地 SVG；新附件保存清洗后的内容，原文件不改动。已有 SVG 附件显示前也清洗，旧字节和历史不改动。移除内容时显示警告，可在消息历史中查看。

仅允许静态 SVG 图形、文字、渐变、裁切及受限的本地形状引用。脚本、事件、样式表、foreignObject、嵌入图片、动画和外部资源均移除；递归引用不允许。SVG 上限 1 MB、5000 个元素。依赖这些被移除功能的图形可能与原图不同；这不是完整的 SVG 编辑器。

验收：
1. 用图片按钮选择 SVG，确认显示；导入含脚本、事件或外部图片的测试 SVG，确认清洗警告且无外部内容。
2. 点击 SVG 或 PNG/JPEG 等图片，在工具栏下调整宽度／高度；勾选保持原始比例时双向联动，取消勾选后独立调整。
3. 拖动缩放滑块。尺寸范围 1–8192 px；默认滑块 1–200%，手动输入更大尺寸后范围扩展。
4. 保存，切换源码与富文本，再重开笔记和程序。HTML 保留 width/height；Markdown 的已调尺寸图片以 img 标签保存。
5. 查看旧 SVG 附件，重命名后重新插入；确认历史、附件导出和移除关联仍正常。

程序回退：退出后用保留的 0.6.0-t06.2 ZIP 替换测试程序；旧版不会显示 SVG 图片，但仍保留附件，带尺寸的 Markdown 可能进入源码保护模式。原文件和笔记本不因程序回退而覆盖。

补充：为了不改变图片所在的标题、列表或表格结构，Markdown 在必要时保留包含已调尺寸图片的受支持 HTML 区块。不是转换整个笔记格式。
