## 使用方法

1. 在全局设置的“AI 设置”中连接提供商，并选择模型。不会自动切换提供商、账户或计费渠道。
   “开启 AI 辅助功能”复选框位于模型提供商之前，默认开启。关闭后隐藏“AI 辅助写作”按钮，重新开启后恢复；开关重启后保留，已有账户和连接设置不删除。
2. 打开笔记，点击合并编辑工具栏中的“AI 辅助写作”。可先选择正文中的文字，再打开此窗口；未选中文字时默认处理全文。
3. 选择润色、改写、扩写、缩写、翻译、续写或自定义操作。选择“翻译”时，在“范围”前出现“目标语言”选择框，支持与界面一致的八种语言；其他要求填写“补充要求”。全局设置的“默认翻译语言”会持久保存并独立于界面语言，未设置时先沿用当前界面语言。写作窗口临时改选不会修改全局默认值。
4. 点击“生成”才发送内容。结果显示在预览中；“插入”放到所选内容后，“替换”替换选区或全文。关闭窗口不会应用结果。应用后的正文仍使用现有保存机制，可通过编辑工具栏撤销／重做。
5. 翻译生成后可点击“保存翻译”，独立于正文保存每篇笔记最近一次翻译。再次打开窗口并选择“翻译”，自动读取保存的内容及目标语言，不发送 AI 请求；只有主动点击“生成”才重新生成。正文或范围变化时保留旧翻译供查看并提示过期，禁用旧结果的插入／替换。
6. 要生成摘要，将操作选为“摘要”，生成后点击“保存摘要”。摘要独立于正文保存；以后打开“AI 写作”窗口可展开查看。修改正文后显示“摘要可能已过期”，不会自动重新生成。

打开、普通保存、搜索和备份不会调用写作模型。真实生成可能使用 ChatGPT 订阅额度或提供商 API 计费额度；自动化只使用模拟提供商，没有使用你的真实凭据或执行收费请求。

## 验收步骤

- 在 TXT／Markdown 源码中分别试选区和全文，检查插入、替换、撤销、重做及保存后重启。
- 在 HTML／Delta 富文本中选中一段文字，检查仅修改该选区，其他内容保持；图片和附件不随请求发送。
- 在全局设置的“全局设置”面板选择默认翻译语言，重启后打开写作窗口并选择“翻译”，检查默认值保留。临时改选后生成，核对实际翻译语言；其他操作不显示目标语言框。修改目标语言会清除旧预览，避免误用旧语言结果。
- 对相同笔记分别使用各操作，核对真实模型返回质量；翻译使用专门的目标语言选择框。
- 生成后关闭预览，应保持正文。请求过程中取消或关闭窗口，不应再显示或应用迟到结果。
- 生成并保存摘要，正文不应改变；修改正文后检查过期提示，重新启动检查摘要仍可读取。
- 加密笔记发送前应出现统一 CDK 确认，显示提供商和实际发送文字长度；取消不发送。锁定笔记本／应用后不能继续应用旧结果。
- 断网、权限不足、额度耗尽、未配置模型时应提示失败，不改正文、不换渠道。重新连接后手动重试。
- 完整笔记本备份、恢复与跨笔记本导入应保留摘要及其来源版本，历史恢复沿用所选版本的摘要。

## 存储与边界

- 摘要最低需要架构 8，保存翻译需要架构 9；本版首次生成摘要或翻译时，会先通过现有 CDK 确认将旧笔记本升级到最新架构 9，并创建完整架构备份。取消升级不生成；普通写作和读取已保存结果不需要升级。
- 摘要记录来源正文版本、来源修订 ID、生成时间、提供商和模型，与笔记元数据及历史一起保存。加密笔记的摘要也加密；列表／搜索／历史列表不回传摘要正文。
- 本轮输出为纯文字。富文本中的全文替换会替换原有正文格式及图片；请先检查预览，必要时使用选区或插入，并可撤销。Delta 源码视图的写作按钮禁用，切回富文本使用。
- Markdown／HTML／TXT 单篇格式导出及 Delta 交换包沿用正文和附件范围，不包含独立摘要或翻译；完整笔记本备份和跨库导入包含二者。
- 本地输入最多 100,000 字符；写作结果最多 64,000 字符，摘要最多 16,384 字符。单次请求超时 120 秒；预览最多保留 10 分钟。提供商自身上下文／输出限制可能更低，失败不自动重试。
- 请求绑定笔记本、编辑会话及笔记版本。保存新版本、删除、结束编辑、切换笔记本、锁定或取消后，旧结果失效。尚未应用的预览仅保留在内存，不写入浏览器存储或日志。

## T12.4 工具栏与保存翻译验收

- HTML／Markdown／Delta 富文本工具栏按粗体、斜体、下划线、删除线、文字颜色、背景颜色、列表排列。窄窗口沿用“更多”菜单。TXT 不显示最前面的竖线。
- 分别选中文字应用这四种格式，检查撤销／重做、源码切换、保存及重新打开。Markdown 的下划线和颜色使用受限制的行内 HTML，兼容普通 Markdown；外部阅读器是否显示取决于其 HTML 支持。
- 翻译生成后先保存翻译，不应改变正文；再次打开并选择翻译，应直接显示旧结果。断开提供商后仍可读取，点击生成才发送新请求。每篇笔记仅保留最近一次已保存翻译，历史版本仍保留此前记录。
- 修改正文、选区、范围或补充要求后检查旧结果过期／清除；保存的翻译可查看，不能覆盖不匹配的新正文。加密笔记锁定后不可读取。
- 翻译最多 64,000 字符，与摘要一起存于修订元数据，元数据总上限 512 KiB；索引／列表不包含翻译正文。新核心支持架构 1–9，原有笔记不自动升级。
