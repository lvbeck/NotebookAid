# T11 AI 连接验收

版本：0.11.0-t11.3。入口：设置 → 全局设置 → AI 连接。

T11.2 修正：页面标题、原生窗口默认标题、托盘提示及 EXE 产品说明统一为 NotebookAid，去掉任务编号。锁屏／解锁／重载标题需保持一致。

T11.1 修正：顶部新增带图标的模型提供商单选，只显示选中提供商的设置；此单选只切换设置面板，实际连接／模型仍由明确的模型选择决定。登录或切换 ChatGPT 账户后自动获取模型，打开已有连接的设置时加载未缓存的模型列表。无模型时显示空结果提示，失败时保留登录并显示具体错误。

按用户要求启用 ChatGPT 自动续期：每 30 秒检查活动账户，到期前 60 秒刷新；断网等暂时失败间隔至少 5 分钟再试，授权撤销后提示重新登录。应用被 Passkey 锁定时暂停，退出时停止；不轮询其他账户、不发送笔记或进行推理。更新包后打开 AI 设置即可自动加载已登录账户的模型，不需要删除凭据或重新注册。

## 本轮范围

- ChatGPT：使用系统浏览器登录，NotebookAid 单独注册；支持多个账户／工作区注册、重新授权、取消、令牌刷新、断开和用量管理。不会读取 Codex 或其他应用的登录凭据。
- Gemini／Claude：输入各自 API Key，默认遮蔽，可用眼睛按钮切换；保存后清空输入框。保存 Key 不等于已验证可用，请主动检查连接。
- 检查只请求官方模型列表；模型名称及 ID 由账户接口提供，不硬编码。选中模型即选定对应连接；不存在自动切换提供商或计费渠道。
- 本轮没有文本生成、摘要或内容发送。这些属于待授权 T12；模型列表成功不代表已验证推理权限或额度。

## 用户操作

1. 点击“使用 ChatGPT 继续”，在系统浏览器中登录并授权 NotebookAid 使用订阅；浏览器回到本机后返回应用。首次成功显示统一 CDK 提示。关闭浏览器不会自动取消，请点击应用中的取消登录；三分钟未完成会超时。
2. 登录完成后模型自动加载，也可点击“检查连接／刷新模型”重试；选择返回的模型。若拒绝订阅权限，应用应显示具体提示且不替换已有连接。
3. 如有其他账户，点击“添加其他账户”。仅在邮箱重复时，账户标签包含注册 ID 后缀，避免同一邮箱下的工作区混淆；切换后自动刷新模型。重新登录同一注册沿用 client ID，断开时保留非令牌注册信息。
4. 分别输入有效 Gemini／Claude Key，保存，检查连接并选择模型。用无效 Key 测试错误提示，用断网测试网络错误；原连接选择不能自动切到别的提供商。
5. 完全退出再打开，确认凭据和模型选择保留；模型清单不缓存到磁盘，打开已连接提供商设置时重新获取当前模型。Key 不应重新出现在输入框。
6. ChatGPT 断开会尝试撤销远程会话，并删除本地令牌。若远程撤销失败，仍在本机断开并提示到 ChatGPT 设置撤销权限。通过“管理用量”打开官方设置。
7. 检查浅色／深色、窄窗口、香港繁体及其他语言，密码默认不可见、按钮可用键盘操作。应用被 Passkey 锁定时，AI IPC 也必须拒绝。

## 安全和回退

凭据只写入 `%APPDATA%\NotebookAid\state\ai-connections.bin`，使用 Electron safeStorage（Windows DPAPI）保护，原子替换；不写日志、浏览器存储、笔记本或笔记备份。不能解密或保护存储不可用时拒绝保存，不降级明文。文件损坏保留原文件。

保持同一 Windows 用户；换电脑／用户需重新连接。回退程序可完全退出后使用保留的 T10 ZIP，通过 Prepare-TestPortable.ps1 部署。旧程序忽略新凭据文件，不用删除该文件；笔记架构未改变。需要撤销服务端权限时在对应提供商账户设置操作。

## 已验证与未验证

已完成生产构建、17 项隔离 AI 测试，以及开发版 Electron 界面、DPAPI、模拟模型列表、取消登录、断网提示和重启测试。OAuth 夹具使用真实 RSA 签名，验证 PKCE、state、nonce、账户身份与权限；网络提供商均模拟，未使用真实账户或收费请求。

首轮隔离测试被沙箱禁止临时文件更名，获工具权限后复测通过；一次自测分支插入位置不正确导致编译／旧界面测试失败，已修正并复测。深色主题测试最初只改主进程设置，未更新 renderer；已改为真实界面操作并检查截图。

最终便携包与部署结果见实施计划。真实 ChatGPT 登录／工作区授权／JWKS／续期、Gemini 和 Claude 账户及模型、Windows 10 均需用户实测；本轮不将模拟成功记录为真实账户成功。
