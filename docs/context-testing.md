## 操作

1. 右键笔记列表卡片，显示带图标和文字的重命名、复制、删除、移动到文件夹、添加标签。沿用 CDK 菜单、现有主题及键盘导航；右键打开菜单本身不写入笔记。
2. 重命名修改指定笔记标题，保存正文未保存的改动后执行。取消不改名，空标题和超过 300 字符的标题不能提交。
3. 复制创建独立副本并打开，保留正文、格式、附件、文件夹、标签、Tasks 只读来源和加密／Thunderbird 隐藏状态；使用新笔记 ID 和独立附件文件。副本不继承历史、置顶及 AI 生成缓存，不修改原笔记，也不新增 Tasks 导入去重记录。
4. 删除沿用现有确认弹窗，确认后移入回收站，可恢复；取消不删除。需要永久删除时仍从回收站操作。
5. 移动支持未分类和全部已定义的文件夹／子文件夹，显示完整层级路径。添加标签保留已有标签，仅添加勾选的新标签；没有可添加标签时显示说明。
6. 正文富文本编辑器和 TXT／源码输入区右键提供剪切、复制、粘贴、全选，均带图标文字。无选区时禁用剪切和复制。使用原选区调用 Electron 的原生编辑命令，粘贴沿用现有 Quill／源码输入、撤销和保存流程。
7. 菜单打开时切换笔记、笔记本或锁定，旧选区和旧会话不能继续修改内容。组合输入／保存切换期间不执行右键写操作。锁定的加密笔记不能复制、重命名、移动或添加标签。
8. 若复制结果状态未知，使用现有错误条的重试／保存或再次复制，重放同一个操作 ID；成功后不会再次生成副本。核心验证所有写入会话、所属进程、版本及文件完整性。

## Markdown 验收修正（0.14.3-context.1）

旧笔记中的内联删除线、下划线或颜色 HTML 含边界空格时，Turndown 自定义规则返回原 HTML，同时默认处理再次添加边界空白，触发严格的转换校验并退回源码模式。本次修正规则的重复空白处理，保留完整内容、嵌套列表及格式校验，不删除笔记格式，也不在打开笔记时重写原文。

人工验收：打开原先受影响的 Markdown 笔记并选择富文本；检查嵌套编号、删除线、粗体、文字颜色和空格，编辑后保存再重新打开。其他仍不支持的结构继续使用源码保护。自动化使用合成示例，未读取或修改真实笔记。

实际验证：构建通过；四项格式核心检查通过（目录链接夹具首次因沙箱 EPERM 失败，允许后重跑全部通过）。开发编辑器 output/editor-packaged/1791926702887 与最终便携编辑器 output/editor-packaged/1791926819954 通过，包括新增内联空白、原文保存重开／富文本编辑以及原有列表、代码、图片、表格、撤销、导出和不支持格式保护。最终右键菜单 output/context-packaged/1791926820980 通过，剪贴板已恢复。五个当前前端文件及三个相关 Runtime 与 ASAR 逐字节一致。初次新增断言要求 Markdown 含普通空格，实际表示使用不换行空格；调整为检查插入文字，原有严格格式往返检查保持不变。
