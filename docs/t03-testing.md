# T03 本地笔记核心验收

版本：0.3.0-t03.2。T02 已获批准，T03 待用户验收。

## 启动与笔记本

先从托盘明确退出 T02，再运行新版 NotebookAid.exe。单实例与桥接沿用原设置；不要同时启动两个版本来编辑同一笔记本。

首次启动创建独立的本地笔记本，默认 `%APPDATA%\NotebookAid\library`。T02 的内存样本没有保存过，不会自动变成正式笔记。界面左下角“选择笔记本”可选择空目录建库或已有兼容库；普通非空目录被拒绝，不在这里做移动或合并。当前路径显示在“技术验证”页。路径偏好暂存于 `%APPDATA%\NotebookAid-T02\library-location.json`；T02 命名仅为沿用桥接运行配置，笔记正文不保存在该配置目录。

请用测试笔记验收。T03 已保存真实文件，但加密、附件、备份和历史管理界面尚未实现。富文本目前仅支持基础 Markdown；遇到识别出的表格、图片、HTML、带语言标记代码块等语法时富文本只读，可以继续在源码中编辑和保存。完整格式转换属 T04。

## 手动测试步骤

1. 点击“新建笔记”，输入中文标题与正文，点击“保存”或 Ctrl+S。确认显示“保存成功”消息、状态为“已保存到本地”；不修改再保存，版本不增加。新建笔记初始标题为 Untitled，可自行改名。
2. 在左下角“全局设置”确认默认开启自动保存、5 分钟。可改为 1–60 分钟，设置即时生效并跨库、重启保留。为测试可先设 1 分钟：修改标题／正文，不点保存，从首次修改计时约 1 分钟，观察状态从“尚未保存”变成“已保存到本地”；继续输入不会重置计时。关闭自动保存后输入并等待，不应自动保存；手动保存、切换笔记和正常退出仍保存。只改标题时 version 增加、contentVersion 不增加；修改正文则二者增加。
3. 新建第二篇，再切回第一篇，确认内容正确。切换前会保存当前编辑；失败时保留当前笔记，不跳走。
4. 输入中文拼音并停留在候选状态，确认组合期间不会重写编辑器或开始自动保存。结束候选选择后观察保存结果。自动测试中的中文字符串不能替代这项真实输入法测试。
5. 修改一处内容后立即从托盘明确退出，再打开，确认最后修改存在。正常退出会等待保存；保存失败时弹出“保留窗口／放弃并退出”，默认保留。关闭窗口仍然隐藏到后台，开启自动保存时计时继续运行。
6. 在“技术验证”中修改 Markdown 源码，等待自动保存；点击“将源码载入编辑器”刷新富文本。若尚未载入，富文本暂时只读以免旧视图覆盖新源码。
7. 在“技术验证”点击“重建索引”，确认显示“索引重建成功”，笔记仍能浏览和打开；有恢复项或损坏文件时提示仍需检查，不显示无条件成功。切勿删除真实唯一笔记本来做破坏试验；异常中断与损坏索引已由开发测试在隔离库执行。
8. 用“选择笔记本”选择另一个空测试目录，创建一篇笔记，再切回原目录。确认两个库内容独立，程序重启后回到最后选择的库。

## 保存、失败与恢复语义

- 标题保存在 `notes/<id>/revisions/<revision-id>/metadata.json`，正文为同目录 `content.md`。当前版本由 `head.json` 指向。笔记 ID 不随标题修改改变。
- 每次提交先将正文与元数据写入 recovery 暂存目录并 fsync，再移到不可变修订目录，校验 SHA256 后原子替换 head.json。替换前终止保持旧版本，替换后终止保持新版本；启动重建索引。
- 索引失败时正文仍可能已保存，界面会单独提示索引待处理；“重建索引”不能删除权威笔记。
- 操作失败时编辑内容留在窗口内，可修复磁盘问题后重试。空标题、超过 300 字符的标题或 UTF-8 超过 2 MiB 的正文会被拒绝。空正文允许保存。
- VERSION_CONFLICT／SESSION_EXPIRED 表示不能继续用旧版本或会话写入。先保留当前草稿文字，再重新打开应用核对笔记，不应通过改文件或版本号强行覆盖。后续任务可以增加专门的冲突比较界面。
- 文件损坏会保留原文件并显示受损笔记 ID；不会用空正文顶替。未提交暂存内容保留在 recovery，提示待检查，不自动提升为当前正文或删除；pendingRecovery 是恢复项数量，可能包含同一未完成操作的多个文件项。
- SQLite 单写入锁与编辑会话分别防止多个核心写同库、旧客户端覆盖，以及编辑中删除。删除限制已有核心测试；用户可见回收站／删除操作属于 T07，插件笔记接口属于 T10。
- 崩溃前仍在内存中的未保存文字不承诺恢复。已测进程强制终止，不等于物理断电、硬盘故障、网络文件系统或第三方云同步并发已获验证；本版本仅面向单机本地库。
- 修订与恢复资料暂不自动清理，持续编辑会增加磁盘占用；历史保留策略在 T07 确定。不能把修订副本当作独立备份。

## 退出与回退

正常退出后可保留所有数据并运行旧 T02 程序验证旧行为；T02 不会编辑 T03 的笔记本。不要删除笔记本、恢复目录或版本目录中的唯一数据。程序包在独立版本目录，可保留旧包；也可退出后运行保留的 T03.1，但其自动保存仍为旧版 1 秒策略；没有迁移用户原有数据。

若要在 Thunderbird 中验证新版后台，请先退出旧后台。若旧目录已注册，先在旧目录运行 Register-Bridge.ps1 -Remove，再在新版目录运行 Register-Bridge.ps1。XPI 仍是 T02 桥接原型，只验证启动／状态／打开窗口，不能浏览笔记；主图标保持不变，XPI 0.2.4 的三个操作按钮增加 Lucide 图标。
