## T03-A 通知与消息中心（2026-10-09 用户已批准）

- [ ] 卡片符合当前浅色／深色主题，默认右下角，可切换四角位置；操作有图标和可访问名称。
- [ ] 铃铛未读计数、抽屉、类型／未读／库筛选、单条／全部标记已读、删除和清空功能正确；关闭卡片不丢失历史。
- [ ] 消息及已读状态重启保留；仅保留最近 100 条，聚合规则按确认方案生效，不影响笔记历史版本。
- [ ] 手动保存／重建显示准确结果；自动保存成功不刷屏，连续失败聚合；未解决错误不被误报为成功。

## T03-B 多笔记库（用户已批准）

- [ ] “选择笔记库”进入已保存列表；显示名称、完整路径、最近打开时间、当前标记与状态，重启仍保留。
- [ ] 添加已有库与新建空库流程明确；移除列表记录后原笔记文件完整，当前库不能被直接移除。
- [ ] 切换前保存草稿，保存失败、目标锁冲突或配置写入失败时留在原库；快速重复切换不串库。
- [ ] 路径失效／离线不静默新建空库；可重新定位同一库；拒绝把普通非空目录当库。
- [ ] Windows 大小写路径不重复登记；不同目录出现同一 libraryId 时提示，不静默合并。
- [ ] 旧版当前路径兼容导入；导入前备份偏好，失败可回退，未改动笔记内容格式。
