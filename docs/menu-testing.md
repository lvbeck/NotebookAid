# 应用菜单验收说明

版本：0.14.2-menu.2。新增 T14-B 应用菜单和信息页面，等待用户验收；T14-A 引导仍待验收，不启动 T15-A。

1. 在定期备份错过时，检查提示文字与“打开设置”按钮垂直居中；窄窗口下可换行。点击按钮进入当前笔记本设置。
2. 主题选择器后显示图标与“应用菜单”文字。菜单依次提供带图标文字的许可证、隐私声明、设置、关于四项；使用鼠标或键盘选择，Esc 可关闭菜单。
   入口不使用 Tooltip，悬停时没有提示文字。菜单项字号与主题选择器相同，图标缩小；关于菜单项显示“关于”。
3. 许可证弹窗显示项目完整 BSD-3-Clause 原文和版权信息，并列出随便携包附带的第三方声明文件。许可证原文保持英文，不将译文当作授权条款。
4. 隐私声明说明本地笔记／附件／设置／通知存储、可选加密、主动 AI 请求、凭据保护与授权续期、Thunderbird 本地桥接、导出及备份。页面本身不登录、不联网、不发送笔记。
5. 关于弹窗显示 NotebookAid 名称、说明、Slogan、实际运行版本、作者 Jin Lu 和联系邮箱 it@live.cn。
6. 三类页面使用统一 CDK 弹窗，标题不添加 info 图标；内容可滚动。关闭按钮、底部关闭按钮、Esc 及背景点击都可关闭，焦点返回菜单入口。
7. 检查八种语言、浅深主题、折叠侧栏和高缩放下的文字、图标、菜单定位及弹窗滚动。全局快捷键不穿透弹窗。

本次不改变笔记本架构或用户数据，不添加依赖、网络接口或新的服务授权。完全退出后可使用保留的 0.14.1-onboarding.1 ZIP 恢复程序文件；设置无需修改。真实键盘、Narrator 及多显示器效果仍需人工验收。
