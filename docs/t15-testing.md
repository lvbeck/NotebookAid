# T15 安装、升级及更新验收

状态：0.15.0-t15.0 开发中，等待用户验收。T15-A 已按用户决定搁置，本包不注册桌面“新建”菜单。此包不是正式 1.0；未发布到外部服务。

## 交付与安装

- Windows x64 安装器：`release/installer/NotebookAid-0.15.0-t15.0-Setup-x64.exe`。
- 便携 ZIP：`release/NotebookAid-0.15.0-t15.0-win-x64.zip`。
- Thunderbird 插件固定名称 `NotebookAid.xpi`，另保留旧插件 ID 的兼容迁移包。
- 向导支持八种界面语言。首次启动使用所选安装语言；既有设置优先，升级不重置语言。
- 可选仅当前用户或本机器所有用户。当前用户模式无需管理员，桥接写 HKCU；所有用户模式需要管理员，桥接写 HKLM 64-bit。每位用户的设置、登录凭据和笔记本注册仍独立。
- 所有用户模式限定在 Program Files 的子目录，以保护共享程序及卸载辅助程序；机器级回滚副本仅管理员及 SYSTEM 可访问。当前用户模式可选择其他空／已受管理目录。
- Windows 会优先使用已有的当前用户桥接注册；从便携版切换到所有用户安装时，请先用旧便携目录的 Register-Bridge.ps1 -Remove 撤销该用户旧注册，避免仍连接旧版本。不会擅自修改其他用户的 HKCU。
- 安装后在 Thunderbird 的“从文件安装附加组件”选择 XPI。安装器不修改 Thunderbird 配置或自动安装插件。

安装／升级／卸载前通过“退出应用”完全退出 NotebookAid 及桥接进程。安装器检测到运行进程会停止，不强制结束应用。只允许空目录或具有有效程序清单的安装目录；不覆盖其他应用目录、带链接的目录或含未知文件的目录。旧便携版请保留并安装到新目录，桥接可以迁移已识别的 NotebookAid 注册。

## 数据保护和升级回退

安装前旧程序文件逐文件复制并验证哈希，回滚副本保存在当前用户 `%LOCALAPPDATA%\NotebookAid\installer-backups` 或所有用户 `%PROGRAMDATA%\NotebookAid\installer-backups`，不会自动删除。副本只包含经过安装清单检查的程序文件，不备份／迁移笔记或密码；笔记数据使用应用自身的备份恢复功能。

卸载仅删除清单中的程序文件及本安装目录拥有的桥接注册，不递归清空目录，不删除笔记和 `%APPDATA%\NotebookAid`。发现未知文件或目录时停止，让用户先检查；不擅自删除。

若升级失败，保存安装日志和回滚副本。完全退出应用，在 PowerShell 中执行保留包里的脚本，`BackupDirectory` 指向升级前副本：

```powershell
.\Recover-Installation.ps1 -BackupDirectory 'C:\完整路径\installer-backups\具体副本'
```

所有用户安装的恢复需要管理员 PowerShell。脚本从备份启动辅助程序，校验全部备份哈希后恢复程序文件和桥接注册，再运行保留的对应旧安装器修复 Windows 卸载信息。缺少有效程序清单、发现未知文件、哈希失败或文件被占用时停止，保留副本和现有文件；不要手动清空目录。脚本执行策略被系统阻止时，不自动绕过策略。回退程序不回退笔记数据。

## 自动更新

用户明确选择先实现机制，发布地址稍后配置。本测试包未配置源或签名，不发起更新请求；便携版显示手动更新说明。设置中可关闭自动检查／下载。

后续发布使用 HTTPS generic feed 和固定签名发布者；必须设置 Windows 代码签名，校验更新 SHA512 和签名，不允许降级。正常退出不会自动安装下载的更新。安装版首次后台检查延后 90 秒，此后每六小时检查一次；可手动检查。下载就绪后用户点击“重启并安装”，确认并成功保存当前编辑后才重启；取消或保存失败不会退出。大版本数据架构迁移仍沿用应用现有确认流程。

## 人工验收

1. Windows 11 安装到含空格／中文路径；测试当前用户及所有用户模式、开始菜单入口、安装语言和现有语言保持。
2. 安装 XPI、连接、打开笔记、重启计算机后连接；确认桥接注册不需要每次重启重做。所有用户模式应在另一个 Windows 用户下验证。
3. 正常升级、失败恢复、卸载、重装；确认笔记、设置、凭据不被卸载删除。先用测试笔记本和数据备份。
4. 安装目录加入一个测试文件后尝试卸载，应停止并保留文件；移走该测试文件后可卸载。
5. 更新设置默认启用，关闭后重启保持；当前无发布地址应明确显示未配置，不自动访问网络。真实 HTTPS／签名端到端更新在配置源后再验收。
6. 真实 Windows 10 和 Thunderbird 157.0.1 基线／选定较新 Release 仍需独立实测，自动化模拟不能替代。

程序回退可使用保留的 0.14.5-easter.3 ZIP。旧版不识别新增 `global.autoUpdates` 字段，完全退出后先备份 settings.json，删除该可选字段再启动旧版；笔记架构没有变化。

7. 在笔记编辑、笔记本设置等页面打开应用菜单，点击“检查更新”，应切换到全局设置并定位应用更新区域，显示检查结果或未配置／便携版说明；切换八语言确认菜单文字和图标。

安装字体修正 0.15.1-t15.1：安装器及卸载器启用 ManifestDPIAware true，简体中文使用 Microsoft YaHei（微软雅黑）9 号，繁体中文使用 Microsoft JhengHei 9 号。请在 Windows 125%、150%、200% 缩放下复测许可证、安装范围、目录、进度及完成页面的文字、按钮、图标与裁切；跨不同 DPI 显示器拖动也须人工检查。此声明采用系统 DPI 感知，不声称逐显示器动态缩放已验证。

新增验收：手动及每日后台备份显示分阶段进度，界面动画和应用菜单保持响应；备份期间笔记本写入暂缓，结束后恢复，检查所有历史版本／加密笔记／附件可恢复。安装程序目录页之后新增快捷方式页面，默认不选桌面、选开始菜单；检查四种组合及当前用户／所有用户路径和卸载清理。完成页使用 NotebookAid 定制蓝紫图片；125%／150%／200% 缩放下检查图片比例、复选框和文字裁切。仍需真实多用户和高 DPI 安装向导人工验收。
