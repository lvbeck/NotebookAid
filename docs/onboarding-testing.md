# 新手引导验收说明

版本：0.14.1-onboarding.1。T14 已由用户验收并提交本地 main：11bca74。本次为单独授权的新手引导功能，等待验收；T15-A 未开始。

## 操作

1. 应用解锁并准备好后，未关闭、未完成的引导显示开始提示；图标和“新手引导”在同一行垂直居中。
2. 点击开始，按笔记本、新建、列表／搜索、编辑／保存、文件夹／标签、设置六个步骤展示聚光灯遮罩。其他区域变暗，提示卡片提供上一步、下一步及结束按钮；方向键切换，Esc 结束。
3. 点击暂不开始或关闭提示，本次启动不再打扰。教学过程中结束会保留当前步骤，下次启动可选择继续。
4. 设置 → 全局设置 → 新手引导：关闭后不再自动提示，继续按钮回到保存的步骤，重新开始清除完成状态并回到第一步。关闭时继续／重新开始按钮禁用，开启后恢复；开启不会清除已完成状态。
5. 完成第六步后显示完成页面，图标和“引导完成”同一行垂直居中。之后重启或切换笔记本都不会自动显示；仍可从设置重新开始。
6. 没有选中笔记时，编辑／保存步骤介绍空状态，不自动创建示例笔记。引导不自动执行导入、保存正文、加密、AI 或目录选择。
7. 检查所有步骤的上一步、下一步和完成按钮：箭头／勾选图标与文字垂直居中；浅深主题和 200% 缩放下保持对齐。教学提示、欢迎页及完成页的关闭按钮没有紫色高亮外框；键盘聚焦关闭按钮时以浅色背景提示焦点。

## 行为与验证

- 使用 Driver.js 1.9.0（MIT），本地打包，不从 CDN 加载。安装包内许可证已核对，并附 DRIVER-JS-LICENSE.txt；项目仍为 BSD-3-Clause。
- 完成、开启及步骤状态只保存到应用全局 settings.json，不保存到笔记本、正文或浏览器存储。旧设置默认开启、尚未开始，不改笔记本架构。
- 每次换步先持久化进度，保存失败不推进，回到设置显示具体失败提示，可重试。正常教学进度不弹出大量设置已保存通知。
- 教学期间保护全局快捷键及背景控件。打开其他 CDK 对话框、原生关闭确认、应用退出或锁定时中断教学，保存的步骤仍可继续。
- 八语言、浅深主题和系统减少动画偏好沿用现有设置。聚光灯随布局变化定位，折叠侧栏及高缩放需检查。
- 隔离自动化覆盖首次提示、稍后、开启／关闭、六步、暂停／进程重启继续、完成后重启不提示、重新开始、关闭后重启不提示、设置写入失败、原生关闭确认及八语言。使用合成空笔记本，检查教学未创建笔记；不操作真实用户笔记或 AI 凭据。
- 实体键盘、输入法、Narrator、多显示器及 Win10 仍需人工验收；自动事件注入不代表这些环境已验证。
