# 批量解除笔记加密验收

版本：0.14.3-context.5。2026-10-14 用户明确验收批量解除加密、侧边栏调整及右键置顶功能；三项均已批准，暂不进行 T15-A。

## 操作

1. 在当前笔记本设置中选择“关闭主密码”。已解锁时列出全部加密笔记的标题、完整文件夹路径和回收站标记；锁定时不显示标题，输入当前主密码并点击继续后解锁、读取列表。
2. 输入当前主密码，点击带图标的“全部解除加密”，再次确认。取消确认不会修改笔记；错误密码不会开始转换或备份。
3. 执行前在笔记本同级的 `<notebook>.security-backups` 目录自动保存完整备份，保留当时的加密文件和密钥材料。备份失败时不开始解除加密。备份可能还包含原本未加密的笔记，整份备份不是额外加密容器。
4. 显示备份阶段与逐篇处理进度。对列表中的所有笔记及回收站笔记解除加密，包括其全部历史和附件，保留内容、版本、文件夹、标签及回收站状态。
5. 每篇复用既有转换事务和文件验证。失败时停止后续处理，显示具体原因，保留主密码及剩余加密笔记；已经成功的笔记保留为明文，可以修复问题后重试剩余项。该批次不是全部笔记的统一原子事务。
6. 全部成功后，窗口显示成功数量、备份路径和“没有已加密笔记”的说明；此时主密码仍开启，点击继续才关闭。也可取消窗口，保留主密码和已解除加密的笔记。

解除后内容会以明文写入笔记本目录。旧备份维持原有保护，仍需保存原主密码或恢复密钥以访问操作前的加密备份。教学、回收站、Passkey 和 Thunderbird 可见性规则不变。

## 验证及边界

自动检查使用隔离笔记本、固定测试密码及模拟内容，不触碰用户笔记或调用 AI。覆盖正常笔记与回收站、历史附件保留、错误密码、占用会话、损坏附件、备份验证、进度、取消确认、关闭主密码及重开内容。实际大笔记本速度、输入法、实体鼠标及真实异常断电仍待人工验收。

实际结果：12 项核心及加密检查通过；开发界面 output/decrypt-packaged/1791964692148 和最终便携专项 output/decrypt-packaged/1791965126122 通过。最终列表截图已检查，剩余加密笔记时“继续”禁用；八语言 72 个文字值完整，前端五文件及八个相关 Runtime 与 ASAR 一致。首轮测试夹具的目标笔记本、监听函数返回值和字符串代次错误修正后通过，未放宽业务权限。

## 回退

完全退出应用后，可用保留的 0.14.3-context.4 ZIP 回退程序；程序回退不会重新加密已经解除的笔记。恢复数据时使用本次报告中的操作前备份，通过既有“恢复备份”流程恢复到目标笔记本，并用原密码解锁。勿删除备份或直接混合复制新旧笔记文件。
