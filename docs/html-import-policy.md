# HTML 导入与编辑边界（T04.7）

## 导入

HTML 导入由主进程在无 Node 权限、无网络访问的隔离解析窗口中调用现有 DOMPurify，然后执行资源／CSS 策略。保存的是处理后的 HTML，原文件不修改。发现删除内容时显示警告，并保留在消息历史；不要求额外确认。普通结构、class、id、title、data-*、ARIA、表格、链接 target、图片 alt／尺寸等尽量保留，解析器可能规范化排版和属性顺序。

删除脚本、事件属性、嵌入页面／对象、base、meta、外部样式表、表单行为和危险链接。非图片媒体地址、srcset、poster 和 CSS 资源加载规则移除；安全图片地址与说明保留，编辑器离线占位，预览不加载外部图片。允许内嵌 base64 PNG/JPEG/GIF/WebP 图片；SVG 等活动资源不导入。外链 a 的安全 href 保留。当前没有网络加载开关。

CSS 保留可解析的声明及规则；移除 url、资源生成函数、旧式脚本表达式和外部导入，不将 CSS 注入应用页面。清理不是网页像素级保真承诺。

## 预览及富文本

复杂 HTML 在源码区编辑；可展开只读隔离预览。预览使用无权限 sandbox iframe，限制资源的 CSP，不启用脚本、表单提交、弹窗、同源访问或顶层导航。页面 CSS 只作用于 iframe。class 对应的外部 CSS 不下载，因此有些网页布局与原网站不同。

Quill 支持现有基础段落、标题、强调、列表、引用、代码和链接；href、target="_blank" 及其默认 rel 可进入富文本。其他 class、id、自定义 target／rel、复杂布局或不能保持的属性仍受源码保护。仅扩大清洗白名单不能使 Quill 无损编辑任意 HTML，不提供强制有损转换。

已有笔记不批量清理；手动源码修改仍按原文保存，隔离预览再次清理显示副本。新要求改变 HTML 文件导入行为，不改变普通保存和同格式导出的契约；导出旧笔记或手写活动 HTML 前仍需自行核对。

## 验收

1. 导入含 class、id、title、表格及图片的 HTML，检查普通结构保留，外部资源地址被移除并出现警告。
2. 导入含 script、onclick、onerror、javascript:、iframe、@import、url() 的样例，检查保存后的源码已清理，警告进入历史。
3. 导入带内嵌样式的 HTML，展开隔离预览，确认样式在预览内生效且不改变应用按钮、字体和背景。
4. 简单链接 target="_blank" 可切换富文本，编辑／保存／重开后 href 保留；复杂布局保持源码可编辑和可保存。
5. 原文件仍可用于重新导入或恢复被移除的资源引用；已经保存的清理结果不会自动恢复被删除的部分。

回退程序使用 release 中旧版本 ZIP，不另做程序目录备份。若需要恢复导入前内容，重新使用原始 HTML 文件；旧版本不会自动补回被清理的内容。T04 仍待用户验收。

## 富文本不支持原因

源码保护面板列出具体标签和属性，以及调整建议。安全属性（例如 class）保留在源码中，即使当前富文本编辑不支持；不因编辑器限制自动删除。修改源码后点击“富文本”重新检查。DOM 元素序号是解析后位置，不是源码行号。无法定位具体原因的往返转换差异单独报告，保留源码，不推测可安全删除的内容。

## T04.7 图片引用修订

新导入 HTML 的安全 img src（HTTP(S)、相对路径、允许的位图 data URI）保留在源码中；显示由编辑器离线占位机制和隔离预览控制，不自动加载外部资源。其他资源元素/活动样式仍清理。此规则覆盖此前直接删除所有外部图片 src 的规则，旧笔记不迁移。
