- 改善浅色辅助文字、深色主要按钮文字对比度；系统要求减少动画时禁用过渡、动画和自动平滑滚动。

## 人工验收

1. 打开设置，在八种语言下检查缩放标签及快捷键说明；切换语言不改变自定义笔记标题、正文、文件夹或标签名称。
2. 在浅色、深色及跟随系统模式下检查主要按钮、下拉菜单、通知和编辑工具。用 Windows 系统主题切换核对跟随系统。
3. 将缩放设为 125% 后完全退出并重启，确认缩放保留；用快捷键恢复 100%。测试 200% 时可滚动到设置及侧栏入口。应用缩放不改变笔记图片尺寸或文件内容。
4. 用 Ctrl+N 打开格式菜单，Tab／Shift+Tab 在其中移动，Esc 关闭；Ctrl+F 聚焦搜索，Ctrl+, 打开设置。打开 Tasks 导入或密码对话框时，这些全局快捷键不应新建笔记、跳页或缩放。
5. 用 Tab 访问下拉框，Enter 打开，方向键／Home／End 选择，Enter 提交，Esc 取消。检查焦点可见、返回位置及选择状态。
6. 使用实际中文输入法候选窗口测试快捷键保护；使用 Windows Narrator 检查选择框名称、选项及密码按钮说明。实际实体键盘、屏幕阅读器及 Windows 显示缩放需要人工验收。
7. 遇到保存失败时，确认正文保留、具体提示可见；提交结果未知时重试相同操作，不另建副本。意外界面错误不显示笔记文字、凭据或完整异常。

## 验证及边界

自动检查使用隔离测试目录和合成笔记，不访问个人笔记或 AI 服务。涵盖语言完整性、设置兼容和非法缩放输入、界面快捷键、组合输入／弹窗保护、八语言浅深主题、实际计算样式文字对比度、选择器键盘导航、缩放重启及匿名化异常提示。事件注入不等于实体输入法或屏幕阅读器测试。
