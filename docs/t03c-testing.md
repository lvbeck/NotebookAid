# T03-C 分层设置验收

版本：0.3.0-t03c.1。T03-B 已通过用户验收，用户明确授权“开始 T03-C”。本任务不包含笔记删除／回收站（T07）、编辑器格式扩展（T04）或 Windows 右键入口（T15-A）。

## 启动与验收

先从托盘明确退出旧版，再运行本版 NotebookAid.exe。侧栏入口已改为“设置”，内部提供“全局设置”和“笔记库设置”。

1. 全局设置包含语言、主题、默认自动保存、通知位置和消息历史入口。顶部语言／主题选择与设置页共用同一配置。新用户仍默认开启自动保存、5 分钟；旧用户导入原值，不重置成默认值。
2. 修改自动保存分钟数（1–60 整数），离开输入栏后提交；复选框和下拉框即时提交。保存成功进入消息中心且默认已读。非法值／写入失败时保留旧值并显示失败信息。
3. 在“笔记库设置”选择已登记库。查看名称、路径和可用／当前状态，可修改本机显示名称。选择设置对象不等于切换正在编辑的库。
4. 所有库默认勾选“继承全局自动保存设置”。取消勾选后，可为该库单独开启／关闭自动保存和设置分钟数。“实际生效设置”显示来源和最终值；“恢复继承全局”移除覆盖值。
5. 将 A 库设为继承、B 库设为关闭定时保存，再修改全局间隔。A 跟随全局，B 保持覆盖。切换到 B 编辑时不应触发定时保存；手动、切库、正常退出仍保存。修改非当前库偏好不会重置当前库计时器。
6. 在库设置选择非当前库／离线库，重建索引应禁用并提示先打开。只有当前且可用的库可维护，不能误重建另一个库。自动保存偏好属于本机配置，离线库仍可修改偏好。
7. 正常退出并重启，检查全局语言／主题、全局保存值及各库覆盖值保留。复核浅色／深色主题、键盘 Tab 及分钟输入提交。

## 数据与升级

- 主进程管理应用配置目录 `%APPDATA%\NotebookAid-T02\settings.json`，schemaVersion=1，保存 global(locale/theme/autosave) 和 libraries(entryId → autosave)。配置校验后以临时文件、fsync 和原子替换保存；失败时运行中和磁盘上的旧值保留。
- 首次导入通过受限 IPC 只传递原 localStorage 的三个已知键：notebookaid.t02.locale、notebookaid.t02.theme、notebookaid.autosave。先备份原值到 settings-legacy.t03c-backup.json，再写新文件；原 localStorage 不删除、不改写。无旧值时使用默认设置。
- 损坏或未知版本的配置保留原件并报错，不自动覆盖。旧偏好格式无效时同样保留备份并阻止导入；设置未能读取时暂停定时保存，但手动保存与正常退出保存仍可用。设置页可重试读取；不要删除唯一的原配置来尝试修复。
- 位置／消息历史继续由既有 notifications.sqlite 管理，设置页统一入口，不迁移通知数据库。libraries.json、笔记正文与修订格式不变。
- 覆盖值关联本机库列表 entry ID；改名／重新定位保留覆盖。移除后重新添加产生新 entry ID，因此默认重新继承全局，原覆盖不会自动套到重新添加的记录。配置不随库文件夹复制到其他电脑。
- 修改当前库生效值会重新计时；普通继续输入、修改其他库偏好或刷新库列表不会延后当前计时器。切库与重新计时会使旧回调失效。无修改不产生新修订。
